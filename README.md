# COMP8240 SimCSE Replication and Extension

This repository contains the code, data-processing workflow, experimental results, analysis, and report source for the COMP8240 major project:

**Replicating and Extending SimCSE**

The project is based on:

Tianyu Gao, Xingcheng Yao, and Danqi Chen. 2021. *SimCSE: Simple Contrastive Learning of Sentence Embeddings*. EMNLP 2021.

Official implementation:
https://github.com/princeton-nlp/SimCSE

The project has three main components:

1. Replication of the original SimCSE semantic textual similarity evaluation and training where feasible.
2. Evaluation of SimCSE on new semantic-similarity data.
3. Construction and analysis of a controlled semantic-perturbation dataset, including human annotation and LLM-as-judge evaluation.

## Repository Structure

- `replication/` — original SimCSE replication scripts and training records
- `data/` — project datasets and processed data
- `evaluation/` — evaluation scripts
- `analysis/` — statistical and error-analysis scripts
- `results/` — experimental outputs
- `figures/` — report-ready figures
- `report/` — ACL LaTeX final report source

Detailed reproduction instructions will be added as the project is finalised.
